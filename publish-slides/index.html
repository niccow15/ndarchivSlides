THE DYNAMICS

3-Majority

A complete graph of n agents,
each holding one of k opinions.

  1. Sample three agents uniformly and independently.
  2. Adopt the majority opinion in the sample.
  3. Three different opinions?
    Break the tie uniformly at random.
How many rounds until all agents hold the same opinion?

All agents update simultaneously. Click an agent to inspect it.

Complete graph · self-sampling allowed · sampling with replacement02
THE DYNAMICS

2-Choices

A more conservative update rule.

  1. Sample two agents uniformly and independently.
  2. If their opinions agree, adopt that opinion.
  3. Otherwise, keep your current opinion.
This rule also favors
more popular opinions.
2-ChoicesRound 0

Sample first. Then commit the entire synchronous round.

The same population model; a different local rule03

Three candidate parameters.

EXAMPLE

Same maximum. Different distributions.

m_0=\frac{1}{\sqrt{n}}in both configurations

Balanced

\sqrt{n} opinions, each with \sqrt{n} supporters.

k=\sqrt{n}\gamma_0=\frac{1}{\sqrt{n}}

Unbalanced

One opinion with \sqrt{n} supporters;
every other agent has a distinct opinion.

k\approx n\gamma_0=\Theta(1/n)

\begin{aligned}&p_i^2+p_i(1-\gamma)\\&=p_i(1+p_i-\gamma)\end{aligned}

\begin{aligned}&m\ge 2\gamma\quad\Longrightarrow\\&\mathbb{E}[C_1^{\prime}\mid\mathbf{p}]\ge nm\!\left(1+\frac{m}{2}\right)\end{aligned}
